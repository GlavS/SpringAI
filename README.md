# Spring Framework — учебный курс

Учебный репозиторий для изучения и повторения **Spring Framework**.  
Проект используется как набор независимых подпроектов (домашних заданий),  
каждый из которых посвящён отдельной теме или технологии.

---

## 📦 Подпроекты

### `hw01-spring-core-xml`
Минимальный проект на **Spring Core**:
- XML-конфигурация контекста
- in-memory база данных
- загрузка данных из CSV-файла

---

## 🎯 Цели репозитория

- закрепить базовые и продвинутые концепции Spring
- отработать архитектурные подходы
- вести историю развития проекта по модулям

---

## 🧭 Навигация

Каждый подпроект содержит собственный `README.md`  
с подробным описанием, требованиями и инструкциями по запуску.
