# hw01-spring-core-xml

Учебный проект, демонстрирующий базовую работу со **Spring Core**  
и конфигурацию контейнера через **XML**.

---

## 🛠 Используемые технологии

- Java
- Spring Framework (Core)
- XML configuration
- CSV
- Gradle

---

## 📋 Описание

Проект реализует:
- минимальную конфигурацию Spring-контекста
- in-memory хранилище данных
- загрузку начальных данных из CSV-файла
- работу с бинами, объявленными в XML

---

## 🚀 Запуск проекта

```bash
./gradlew :hw01-spring-core-xml:run
